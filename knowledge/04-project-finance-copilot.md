# 项目深挖：财务报销审核 Agent / Finance Copilot（公开版）

> 钉钉嵌入式财务报销 AI 预审系统：在钉钉报销审批流程中插入 AI 预审节点，自动完成从单据读取到审核报告回写的全流程。

## 双 Agent 分层架构

- **DataGovernanceAgent（数据治理）**：原始审批 payload → 附件解析（MinerU 文档解析服务 + pypdf 本地降级）→ LLM 表单语义提取（canonical 键 + 置信度评分 + 原文引用，低置信度自动 regex 降级）→ 金额勾稽（发票号 + SHA 去重）→ 输出带 dataVersion 哈希的标准化数据。数据治理与业务判定分离，因此复审接口可跳过附件解析直接复用治理结果。
- **ContentJudgementAgent（内容判定）**：只消费治理后的数据，执行五车道判定与决策。

## 五车道审核架构

规则每条以 JSON 声明自己的车道（document 附件证据 / regex 表单正则 / calculator 确定性金额计算 / llm 语义审核 / decision 聚合）、severity、blocking、算子与表达式、以及制度条款出处。**数值与规则算子永远不交给 LLM**：确定性沙箱实现 17 类算子（分项金额勾稽、补贴标准、招待费限额、住宿标准等），并以"基础算子类 + 注册器 + 装饰器自动发现"做成可插拔引擎。

## LLM 隔离护栏

system prompt 明确约束 LLM：不能单独决定审批通过、不得重新计算或覆盖确定性沙箱的结论、低置信度（<0.55）或与确定性规则冲突时强制降级。置信度融合按公式：0.40×LLM + 0.25×证据充分度 + 0.20×规则一致性 − 0.15×冲突惩罚；无 LLM 时退化为规则+证据加权。最终决策四级：PASS / RISK / MANUAL_REVIEW / BLOCK，附一句话判定理由。

## 三阶段审核流程

员工预审 → 主管审核 → 财务交叉审核，阻断时按阶段分派处置动作（退回员工 / 当前节点停留 / 财务强制介入）；支持人工改判且保留原始 AI 结论。

## 钉钉集成

- 入口 HMAC-SHA256 验签 + 5 分钟时间窗防重放；审批单递归解析表单控件（按控件 ID / bizAlias / 名称三重匹配映射标准字段）；自动提取关联出差审批单。
- 附件下载含 SSRF 防护（强制 HTTPS、拒绝私网地址）；压缩包安全解压带五重限制（深度/数量/总量/单文件/压缩比）。
- 回写采用 outbox 模式：审核 PDF 与发票 Excel 上传审批钉盘空间，评论携带文件附件回写审批单，幂等重试、payload 摘要校验；正常流程不自动同意/驳回审批。

## 审核报告

XeLaTeX 生成中文 PDF：结论 banner、执行摘要、置信度分解表（LLM/证据/规则一致性/冲突惩罚分项）、金额核对、确定性核算表、风险表（带证据来源与建议）、问题-证据表（原文摘录引用）、逐附件预览附录（PDF/图片/压缩包展开件）；另生成发票汇总 Excel。

## 工程质量

- 约 1.5 万行 Python + 3,172 行测试（87 个 pytest：决策矩阵、验签重放、幂等去重、勾稽、报告版式等）。
- 真实生产 E2E 联调记录：发现并修复"空环境变量覆盖 TOML 配置"等 bug，明确"正式审批实例只读、测试模板零副作用"的安全边界。
- 保留 6 组真实历史报销案例作为影子审核对照集；PII 脱敏 + 泄漏检测；HARD/SOFT/OPTIONAL 三级启动健康检查；PostgreSQL 队列（FOR UPDATE SKIP LOCKED）替代消息中间件，单体 + 异步 Worker 架构，按日处理 <500 单设计。
