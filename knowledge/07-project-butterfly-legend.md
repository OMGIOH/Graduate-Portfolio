# 作品深挖：《鼓藏之灵·蝴蝶传说》（AIGC 文化转译流水线）

> 取材苗族古歌创世史诗"蝴蝶妈妈（妹榜妹留）"的 AIGC 动画影像：4 分 33 秒、7 场，讲述枫香树→蝴蝶妈妈→与水泡游方→十二个蛋→鹡宇鸟孵化→人类始祖姜央→鼓藏节由来的创世叙事。本人为第一作者（团队三人，指导教师一名）。

## 赛事成果

- **IDHFUS 2026 首届大学生国际数字人文节**（中国人民大学信息资源管理学院、数字人文研究院主办，主题"遗产·记忆·视界"）：从两百余份参赛作品中入围"优秀入围作品"，2026 年 9 月现场展出。
- **AIC 全球校园人工智能算法精英大赛 · 算法主题赛智能文化赛道**（2025 年第七届）：以同一作品完整提交作品简介、技术报告、答辩材料与演示视频。

## 方法亮点：可解释、可溯源的 AIGC 文化转译流水线

文化 AIGC 的核心难题是"异源文献说法打架、生成内容无从考据"。本作品的做法：

1. **资料采集**：自研爬虫脚本全网采集苗族古歌资料，汇编为 50 条 GB/T 7714 规范引文的来源库（百科、非遗网站、贵州数字村寨、省博物馆、学术论文等）。
2. **置信度知识图谱**：手工构建 40 实体 / 58 关系的知识图谱，每个三元组带置信度标注，配 HTML 可视化。
3. **KG2Narrative 自研流水线（五阶段）**：BFS 提取叙事主干 → 置信度加权的版本冲突解决 → 普罗普叙事功能理论切分 7 场 → 低置信度处由"叙事润滑剂"补充细节 → 自然语言模板生成剧本。
4. **可溯源提示词工程**：脚本从剧本生成 15 条 AIGC 绘图提示词（适配即梦 AI / Midjourney / Stable Diffusion 风格）。
5. **反向溯源**：trace_reverse 工具把每个剧本段落回指知识图谱实体、再回指原始文献，产出 79 条引证的溯源报告——每一帧画面都能回答"依据是哪本文献的哪一处"。

## 技术栈

Python（requests + BeautifulSoup 爬虫、资料汇编）、知识图谱构建与可视化、KG2Narrative / kg2prompt / trace_reverse 自研工具链、即梦 AI 等生成式工具、HTML/CSS/JS 移动端展示页（canvas 粒子背景、视频嵌入，部署于 GitHub Pages）、Puppeteer 导出 80×120cm 印刷级学术海报（deviceScaleFactor 3x ≈ 300DPI，含完整踩坑记录）、python-pptx 脚本群批量生成展演 PPT。

## 意义

这是"知识图谱 + 叙事推理 + AIGC"做数字人文文化转译的完整方法论验证——先在苗族古歌小图谱上把"图谱→叙事→生成→溯源"链路跑通，为后续布依族古歌课题（更大规模语料、自动化图谱构建、幻觉检测）奠定了方法论基础。
